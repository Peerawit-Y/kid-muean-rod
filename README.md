**"คิดเหมือนรอด"** เป็น Interactive Real-Time Web Application สำหรับใช้ในชั้นเรียนขนาดใหญ่ (30–100+ คนพร้อมกัน) ตามแนวคิด:

> **"คุณจะรอด... ถ้าคิดเหมือนคนส่วนใหญ่"**  
> ผู้เล่นไม่ได้แข่งขันกันหาคำตอบที่ถูกต้องตามตำรา แต่ต้องใช้จิตวิทยาการคาดเดาความคิดของเพื่อนส่วนใหญ่ในห้อง เพื่อเลือกคำตอบ A, B, C หรือ D ที่ได้คะแนนโหวตสูงสุด (Majority)!

---

## 🌟 ฟีเจอร์ที่ได้รับการอัปเกรดล่าสุด

### 🎬 1. ด้านประสบการณ์และความตื่นเต้น (Presentation & Game Show FX)
- **🥁 แอนิเมชันเปิดผลแบบไต่ระดับ (Suspense Staggered Reveal):**
  - เมื่อจบรอบ ระบบจะไม่เปิดผลพร้อมกันทันที แต่จะค่อยๆ วิ่งแถบคะแนนทีละข้อ (A ➔ B ➔ C ➔ D) พร้อมเสียงคอร์ดดนตรีสังเคราะห์
  - ตามด้วยเสียงรัวกลอง (Drumroll) และสปอตไลต์สีทองสวมมงกุฎให้ตัวเลือก **Majority 👑** อย่างตื่นเต้นเร้าใจ
  - มีปุ่ม **"⏩ แสดงผลทันที"** ให้อาจารย์กดข้ามแอนิเมชันได้ตลอดเวลา
- **🖥️ โหมดโปรเจกเตอร์คอนทราสต์สูง (Projector Theater Mode):**
  - ปุ่มสลับธีมบนแถบเมนูด้านบนของหน้าจอ Host ปรับหน้าจอเป็นสีเข้มคมชัด แสงตัวหนังสือสว่างจ้าและตัดขอบนีออน (Neon Borders) เหมาะสำหรับฉายจอโปรเจกเตอร์ขนาดใหญ่ในห้องเลกเชอร์ 100 คน
- **🎵 ชุดเสียงสังเคราะห์ Web Audio API:**
  - สร้างเสียงเอฟเฟกต์ด้วยคลื่นความถี่ในตัวเครื่องเบราว์เซอร์ ไม่ต้องพึ่งพาไฟล์ MP3 ภายนอก

### 🛡️ 2. ด้านความเสถียรและความปลอดภัยในห้องเรียน (Network & Security)
- **🔒 รหัส PIN ควบคุมห้อง (Host PIN Protection):**
  - ตั้งรหัสผ่านสั้นๆ สำหรับอาจารย์ (ค่าเริ่มต้น: `1234`) เพื่อป้องกันไม่ให้นักศึกษาแอบเปิดหน้า `/?page=host` มากดควบคุมห้องเอง
- **🔄 ระบบกู้คืนเซสชันเมื่อเน็ตหลุด (Auto-Reconnection & Session Resume):**
  - เมื่อผู้เล่นเข้าห้อง ระบบจะออกโทเคนลับ `playerToken` บันทึกไว้ในเครื่อง
  - หากนักศึกษาสลับแอป หน้าจอดับ หรือสัญญาณ Wi-Fi/4G สะดุด ระบบจะกู้คืนสถานะรอบ คำถามที่ตอบ และคะแนนสะสมกลับมาให้อัตโนมัติในเสี้ยววินาทีโดยไม่ต้องเริ่มใหม่
- **🚫 ตัวกรองคำหยาบคาย (Profanity Filter):**
  - ตรวจสอบชื่อผู้เล่นทั้งภาษาไทยและภาษาอังกฤษ หากมีคำไม่สุภาพ ระบบจะแจ้งเตือนให้เปลี่ยนชื่ออย่างสุภาพทันที
- **👥 ป้องกันชื่อซ้ำ (Duplicate Name Prevention):**
  - ป้องกันนักศึกษาพิมพ์ชื่อซ้ำกับเพื่อนในห้องเดิม เพื่อความชัดเจนในการเช็กชื่อและตัดเกรด

## 🚀 วิธีการเปิดใช้งานบนเครื่องของคุณ (Localhost)

### 1. รันเซิร์ฟเวอร์
```bash
npm start
```
หรือหากต้องการให้เซิร์ฟเวอร์รีโหลดตัวเองอัตโนมัติเมื่อแก้โค้ด:
```bash
npm run dev
```

### 2. รันชุดทดสอบระบบ (E2E Test Suite)
```bash
npm test
```

### 3. เปิดใช้งาน
- **หน้าผู้เรียน (เข้าเล่น):** [http://localhost:3000](http://localhost:3000)
- **หน้าจออาจารย์/ผู้จัด (Host):** [http://localhost:3000/?page=host](http://localhost:3000/?page=host) *(PIN: `1234`)*

## ☁️ วิธีการขึ้นระบบออนไลน์ฟรี (Render.com + UptimeRobot)

1. นำโฟลเดอร์นี้ขึ้น GitHub
2. สร้าง Web Service บน [Render.com](https://render.com) (เลือกแผน Free ไม่ต้องใช้บัตรเครดิต)
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
3. นำ URL ที่ได้จาก Render ไปตั้งค่ามอนิเตอร์บน [UptimeRobot.com](https://uptimerobot.com) ให้ Ping ทุกๆ `5 นาที` เพื่อป้องกันไม่ให้เซิร์ฟเวอร์หลับครับ
